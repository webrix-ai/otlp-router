OTLP Router by Willow is installed.

Agents in the cluster send to:
  OTLP/gRPC  {{ include "otlp-router.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.otlpGrpcPort }}
  OTLP/HTTP  http://{{ include "otlp-router.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.otlpHttpPort }}
{{- if .Values.ingress.otlp.enabled }}
  External   https://{{ .Values.ingress.otlp.host }}
{{- end }}

Open the UI:
{{- if .Values.ingress.admin.enabled }}
  https://{{ .Values.ingress.admin.host }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "otlp-router.fullname" . }} {{ .Values.service.adminPort }}
  then http://localhost:{{ .Values.service.adminPort }}
{{- end }}

Sign in as "{{ .Values.auth.admin.username }}". Password:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "otlp-router.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d; echo
{{- if not .Values.auth.ingestTokens }}

WARNING: auth.ingestTokens is empty, so anyone who can reach the OTLP ports can send telemetry.
{{- end }}
